A program that writes one word: the single word grandma would text about AI — "robit", the typo she actually makes when she means robot.

## The word

**robit** — five letters, one word, no newline. Grandma means "robot", her
phone disagrees, and she sends it anyway. Warm, baffled, and unmistakably
about a machine.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

The program writes `entry.txt` with exactly the word and no trailing
newline (5 bytes, UTF-8, inside the 1–30 character gate). It is
deterministic by construction: the word is a constant, so two runs produce
byte-identical output.
